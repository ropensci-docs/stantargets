# Simulate example data for [`tar_stan_example_file()`](https://docs.ropensci.org/stantargets/reference/tar_stan_example_file.md).

An example dataset compatible with the model file from
[`tar_stan_example_file()`](https://docs.ropensci.org/stantargets/reference/tar_stan_example_file.md).

## Usage

``` r
tar_stan_example_data(n = 10L)
```

## Format

A list with the following elements:

- `n`: integer, number of data points.

- `x`: numeric, covariate vector.

- `y`: numeric, response variable.

- `true_beta`: numeric of length 1, value of the regression coefficient
  `beta` used in simulation.

- `.join_data`: a list of simulated values to be appended to as a
  `.join_data` column in the output of targets generated by functions
  such as
  [`tar_stan_mcmc_rep_summary()`](https://docs.ropensci.org/stantargets/reference/tar_stan_mcmc_rep_summary.md).
  Contains the regression coefficient `beta` (numeric of length 1) and
  prior predictive data `y` (numeric vector).

## Arguments

- n:

  Integer of length 1, number of data points.

## Value

List, dataset compatible with the model file from
[`tar_stan_example_file()`](https://docs.ropensci.org/stantargets/reference/tar_stan_example_file.md).

## Details

The `tar_stan_example_data()` function draws a Stan dataset from the
prior predictive distribution of the model from
[`tar_stan_example_file()`](https://docs.ropensci.org/stantargets/reference/tar_stan_example_file.md).
First, the regression coefficient `beta` is drawn from its standard
normal prior, and the covariate `x` is computed. Then, conditional on
the `beta` draws and the covariate, the response vector `y` is drawn
from its Normal(`x * beta`, 1) likelihood.

## See also

Other examples:
[`tar_stan_example_file()`](https://docs.ropensci.org/stantargets/reference/tar_stan_example_file.md)

``` r
#>  [7]  0.3333333  0.5555556  0.7777778  1.0000000
#> 
#> $y
#>  [1]  1.6553606 -1.3483409  0.7722307  1.0882339  1.3039720 -1.9773781
#>  [7] -0.7140065 -1.0220016 -1.3716282 -1.9537429
#> 
#> $true_beta
#> [1] -1.400044
#> 
#> $.join_data
#> $.join_data$beta
#> [1] -1.400044
#> 
#> $.join_data$y_rep

#> 
#> 
```
